# ピアノのたまご

5さいからのピアノ練習アプリ（単一HTML + PWA）。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JS すべて内包） |
| `manifest.json` | ホーム画面インストール設定 |
| `sw.js` | オフライン用 Service Worker |
| `icon-192.png` / `icon-512.png` | PWAアイコン |
| `icon-180.png` | iOS ホーム画面用アイコン |

## 公開手順（GitHub Pages）

1. Public リポジトリを作成（例: `PianoEgg`）
2. 上記6ファイルを**ルート直下**にアップロード（フォルダを作らない）
3. Settings → Pages → Source: `Deploy from a branch` / Branch: `main` `/(root)`
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開
5. iPad の Safari で開く → 共有 → **ホーム画面に追加**

パスはすべて相対（`./`）指定。プロジェクトサイトは `/<リポジトリ名>/` 配下に置かれるため、
絶対パスに書き換えると Service Worker が動かなくなる。

## 更新するときの必須作業

`sw.js` の1行目付近

```js
const CACHE = 'piano-egg-v1';
```

の数字を **必ず上げる**（v1 → v2）。上げないとキャッシュが効いたままで、
端末は古い版を表示し続ける。「直したのに変わらない」の原因はほぼこれ。

## データの保存先

`localStorage`（端末ローカル）。サーバーには何も送信しない。

- iOS ではホーム画面版と Safari タブ版でストレージが別扱いになる。
  ホーム画面版を使い始めたら、以後はそちらだけを使うこと。
- 端末を初期化すると記録は消える。

## 画面

- **きょう** — たまごタイマー（練習時間）、ミッションガチャ、今週の記録
- **おと** — 鍵盤で自由に音出し／音あてクイズ
- **おんぷ** — うえ・した（高低の方向感覚）／音符クイズ（3レベル）
- **リズム** — まねっこリズム（コール&レスポンス）、メトロノーム（2/3/4拍子）
- **ずかん** — 生まれた仲間のコレクション

## 使い方の方針（おうちのひとへ）

- 音符は1日3分まで。楽譜に「ドレミ」を書き込ませない。
- メトロノームは曲の最初の30秒だけ。合わせ続けると演奏が固くなる。
- リズムのまねっこは立ってやる。
