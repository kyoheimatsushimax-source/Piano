# ピアノのたまご — v2（メトロノーム刷新）

## このバージョンの変更点

### 1. メトロノームを「弧を描いて落ちるボール」に変更
点滅は着地の瞬間を予測できないため、リズム感（＝拍を先読みする力）の訓練になりません。
ボールが放物線を描いて落ち、**着地した瞬間が拍**。上がっている間に「次はここ」と体が準備できます。
点滅がほしい場合は `ピカッ` トグルで補助表示としてONにできます。

### 2. 拍子を6種類から選択
| ボタン | 大きな拍 | 1拍の分割 |
|---|---|---|
| 2びょうし | 2 | 2 |
| 3びょうし | 3 | 2 |
| 4びょうし | 4 | 2 |
| 8ぶんの6 | 2 | 3 |
| 8ぶんの9 | 3 | 3 |
| 8ぶんの12 | 4 | 3 |

複合拍子（8分の6/9/12）は **「大きな弧2つ、その中に粒3つ」** の二層表示。
1〜6と数えさせないための設計です。

### 3. テンポ表示が拍子に追従
複合拍子のBPMは **付点4分音符＝大きな拍**。単純拍子と同じ数字だと速すぎるため、
プリセットを自動で切り替えます（単純 56/76/96、複合 40/52/66）。表示も `♩=76` / `♩.=52` と出し分け。
±ボタンで2ずつ微調整（40〜160）。

### 4. ことばモード
拍ごとに3モーラ語（いちご・みかん・ばなな・さくら）／2モーラ語（もも・なし・くり・かき）を表示。
数字を使わずに分割を身につけるためのものです。

### 5. タイミング精度の修正（重要）
旧版は `setInterval` で刻んでいたためブラウザのタイマー精度でズレていました。
`AudioContext.currentTime` を基準にした**先読みスケジューラ**（25ms間隔で120ms先までを予約）に変更。
実測で1小節2.3077秒に対し誤差ゼロ、長時間走らせても累積ドリフトなし。

## 更新手順
1. ZIPを展開し、既存リポジトリ `Piano` のファイルを**丸ごと差し替え**てpush
2. iPadでホーム画面のアプリを一度閉じて開き直す（`sw.js` のCACHEをv2に上げてあるので自動更新されます）

> 次にアプリを更新するときは、`sw.js` の `CACHE` を必ず `v3` に上げてください。

## 使い方（練習の順番）
1. **4びょうし → ふつう** から。ボールの着地に合わせて手拍子。
2. 安定したら **8ぶんの6 → ゆっくり**。`ことば` をONにして「いちご・みかん」と声に出す。
3. 慣れたら `こまかい おと` をOFF。大きな拍2つだけを聴いて、3分割は自分の声で埋める。
   ここまでできれば6/8は体に入っています。

**やらないこと：** 拍子記号の意味を説明する。5歳には不要で、混乱のもとです。
