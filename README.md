# ピアノのたまご — v3.1（わおんあて追加）

## このバージョンの変更点

**v3.1**：「はじめて」の あめ を ド・ミ♭・ソ に変更（v3の和音は実際には明るめに聞こえ、はれと区別しにくかったため）。

### 「おと」タブに「わおんあて」モードを追加
和音を聴いて、**☀️ はれ（明るい）** か **☔️ あめ（暗い）** かを当てる遊びです。

| レベル | 出てくる和音 |
|---|---|
| はじめて | ド・ミ・ソ（はれ）／ド・ミ♭・ソ（あめ）の2つだけ。まんなかの音が半音ちがうだけ |
| いろんな たかさ | はれ：ド・ミ・ソ／ファ・ラ・ド／ソ・シ・レ　あめ：ラ・ド・ミ／レ・ファ・ラ／ミ・ソ・シ |

- 「はれの おと」「あめの おと」ボタンで、いつでも聴き比べられる
- 正解すると、その和音の音名（例：ド・ミ・ソ）を表示する。ほんもののピアノで押してみるきっかけにするため
- 正解するたびに 🌈 がたまる（まちがえても減らない）。まちがえたときは「もういちど きいてみよう」と再生するだけ
- C・Am などのコード記号は表示しない（6歳には不要なため）
- 「いろんな たかさ」は、音の高さではなく響きの明るさで聴き分ける練習
- 同じ和音が3回続けて出ないようにしている

### その他
- アイコンのファイル構成を標準に統一（`icon-180.png` → `apple-touch-icon.png`、`icon-maskable-512.png` を追加）。絵は変えていません

## ファイル構成（すべて同じ階層。サブフォルダは作らない）
```
index.html             アプリ本体（単一HTML・外部依存なし）
manifest.json          PWA設定
sw.js                  Service Worker（CACHE = piano-egg-v4）
apple-touch-icon.png   180×180（iPhone/iPadのホーム画面用）
icon-192.png
icon-512.png
icon-maskable-512.png  余白付き（Android用）
README.md
```
サブフォルダを作らないのは、GitHubのWeb画面（特にiPhone）からアップロードするとフォルダ階層が消え、アイコンのパスがずれて表示されなくなるためです。

## 更新手順（GitHub Pages）
1. ZIPを展開し、リポジトリ `Piano` の直下に8ファイルを**すべて上書き**でアップロード（Add file → Upload files）
2. 古い `icon-180.png` は残っていても動作に影響しません（不要なら削除可）
3. iPadでホーム画面のアプリを一度閉じて開き直す（今回からページ本体はネットにつながっていれば最新版を読みに行きます）

> 次にアプリを更新するときは、`sw.js` の `CACHE` を必ず `v5` に上げてください。

## アイコンが反映されないとき
1. `https://kyoheimatsushimax-source.github.io/Piano/apple-touch-icon.png` を開いて絵が出るか確認
2. ホーム画面のアイコンは追加した時点の画像で固定されます。ホーム画面から削除し、Safariで開き直して再追加
3. それでも古ければ、設定 → Safari → 詳細 → Webサイトデータ から github.io を削除して再追加

## わおんあての使い方（おすすめの順番）
1. 最初は答えさせない。「はれの おと」「あめの おと」を交互に鳴らして「どんな感じ？」と話す
2. 「はじめて」レベルで当てっこ。親が先に答えない
3. 慣れたら、ほんもののピアノで「ド・ミ・ソ」を押し、まんなかのミだけを左どなりの黒いけんにずらしてみる
4. 「はじめて」でほぼ当たるようになったら「いろんな たかさ」へ

**やらないこと：** 正解率をチェックする、C・Am などの記号を教える。

## 既存機能の使い方（リズム）
1. **4びょうし → ふつう** から。ボールの着地に合わせて手拍子。
2. 安定したら **8ぶんの6 → ゆっくり**。`ことば` をONにして「いちご・みかん」と声に出す。
3. 慣れたら `こまかい おと` をOFF。大きな拍2つだけを聴いて、3分割は自分の声で埋める。

## 技術メモ（v3）
- 和音・チャイムが重なっても音割れしないよう、出力の最後にコンプレッサーを挟んだ
- 画面やレベルを切り替えたとき、前の画面で予約されていた音や次の問題が後から鳴らないようにした（おとあての既存不具合も同時に修正）
- v3.1：「はじめて」のあめを ド・ミ♭・ソ に変更。v3では ド・ミ・ラ の上に低いドを足して鳴らしていたため、実際には明るめの響き（C6）になり、はれとの区別がつきにくかった
- sw.js：古いキャッシュの削除を `piano-egg-` で始まるものだけに限定（github.io を共有する他の自作アプリのキャッシュを消さないため）。ページ本体はネットワーク優先に変更
